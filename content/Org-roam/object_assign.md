# Object.assign

# Description

\~Object.assign~ copies all properties from one \[JavaScript Objects]\(JavaScript Objects) into another

# Syntax

```js
let objectA = { a: 1, b: 2 };
Object.assign(objectA, { b: 3, c: 4 });
console.log(objectA);
```
