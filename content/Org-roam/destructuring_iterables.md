# Destructuring Iterables

- [Introduction](#introduction)
- [Syntax](#syntax)

# Introduction

This was introduced in [ES6](ES6). Destructuring \[JavaScript Iterables]\(JavaScript Iterables) works on the same principle as \[Destructuring Arrays]\(Destructuring Arrays).

# Syntax

```js
const [x,...y] = 'abc'
console.log(x, y) // a ['b', 'c']
```
