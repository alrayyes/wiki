# JavaScript String To Array Conversion

## Description

Strings can be [[JavaScript Type Conversion]] into [[JavaScript Arrays]] with the [[Spread (...)]] operator:

## Syntax

```js
const chars = [..."abc"];
console.log(chars); // Array(3) [ "a", "b", "c" ]
```
