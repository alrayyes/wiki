# str\_ends\_with()

# Description

Check if string ends with other string. Opposite of [str\_starts\_with()](str_starts_with\(\)). See RFC\[fn:rfc] for more details.

# Syntax

str\_ends\_with('haystack', 'stack') // true

# Footnotes

\[fn:rfc]https://wiki.php.net/rfc/add\_str\_starts\_with\_and\_ends\_with\_functions
