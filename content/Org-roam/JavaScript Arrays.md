# JavaScript Arrays

- [[JavaScript Array Prototype Methods]]
- [[JavaScript Array Functions]]
- [[Destructuring Arrays]]

## Syntax

```js
let listOfNumbers = [2, 3, 5, 7, 11];
console.log(listOfNumbers[2]); // 5
console.log(listOfNumbers[0]); // 2
```

## Type

In JavaScript arrays are a type of [[JavaScript Objects]] that store sequences of things. ~typeof~ wil therefore return "object"

```js
let listOfThings = ["Car", "Mr Magoo", 42];

console.log(typeof listOfThings); // object
```
