# createFromInterface()

# Description

Similar to [createFromImmutable()](createFromImmutable\(\)), but this method creates a date from any object that uses ~DateTimeInterface~

# Syntax

DateTime::createFromInterface(DateTimeInterface $other);
DateTimeImmutable::createFromInterface(DateTimeInterface $other);
