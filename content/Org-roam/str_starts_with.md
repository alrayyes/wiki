# str\_starts\_with()

# Description

Checks if string starts with other string. Opposite of [str\_ends\_with()](str_ends_with\(\)). See RFC\[fn:rfc].

# Syntax

str\_starts\_with('haystack', 'hay') // true

# Footnotes

\[fn:rfc]https://wiki.php.net/rfc/add\_str\_starts\_with\_and\_ends\_with\_functions
