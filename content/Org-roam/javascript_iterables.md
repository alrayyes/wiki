# Introduction

An /iterable/ is a data structure that wants to make its elements accessible to the public. It does so by implementing a method whose key is \[\[https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global\_Objects/Symbol/iterator]\[Symbol.iterator]]. That method is a factory for \[JavaScript Iterator]\(JavaScript Iterator).
