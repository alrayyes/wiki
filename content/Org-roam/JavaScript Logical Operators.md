# JavaScript Logical Operators

## Syntax

```js
console.log(true && false)
console.log(true && true)
console.log(false || true)
console.log(false || false)
```

! is a unary operator that flips the value given to it

```js
console.log(true && !true)
console.log(true && !false)
```
