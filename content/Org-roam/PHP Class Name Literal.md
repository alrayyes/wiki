# PHP Class Name Literal

## Description

Introduced in [[PHP 8.0]], class name literals[^literals] is a new alternative to ~get\_class()~

## Syntax

```php
$foo = new Foo();
var_dump($foo:class)
```

## Footnotes

[^literals]: https://wiki.php.net/rfc/class_name_literal_on_object
