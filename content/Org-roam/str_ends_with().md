# str\_ends\_with()

## Description

Check if string ends with other string. Opposite of [[str_starts_with()]]. See RFC[^rfc] for more details.

## Syntax

```php
str_ends_with('haystack', 'stack') // true
```

## Footnotes

[^rfc]: https://wiki.php.net/rfc/add_str_starts_with_and_ends_with_functions
