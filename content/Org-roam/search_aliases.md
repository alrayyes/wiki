# Search Aliases

# Description

\~#\[doc(alias = "<alias>")]~ can be specified on items to add search aliases when searching through [rustdoc](rustdoc) UI. See the PR\[fn:PR] for more information.

# Syntax

\#\[doc(alias = "bar")]
struct Foo;
