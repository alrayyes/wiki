# ES2017

## Description

What's new in ES2017

## Async functions

### Fulfilling a [[JavaScript Promises]]

```js
async function asyncFunc() {
  return 123;
}

asyncFunc().then((x) => console.log(x));
// 123
```

### Rejecting a [[JavaScript Promises]]

```js
async function asyncFunc() {
  throw new Error("Problem!");
}

asyncFunc().catch((err) => console.log(err));
// Error: Problem!
```
