# createFromImmutable()

# Description

Similar to [createFromInterface()](createFromInterface\(\)), but this function creates a ~DateTime~ object from a ~DateTimeImmutable~ one.

# Syntax

DateTime::createFromImmutable(new DateTimeImmutable())
