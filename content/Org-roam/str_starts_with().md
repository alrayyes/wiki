# str\_starts\_with()

## Description

Checks if string starts with other string. Opposite of [[str_ends_with()]]. See RFC[^rfc].

## Syntax

```php
str_starts_with('haystack', 'hay') // true
```

## Footnotes

[^rfc]: https://wiki.php.net/rfc/add_str_starts_with_and_ends_with_functions
