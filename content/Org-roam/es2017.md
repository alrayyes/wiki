# Async functions

## Fulfilling a \[\[id:14e0ce4b-b4b1-46fe-946a-c519550682ac]\[promise]]

```js
async function asyncFunc() {
  return 123;
}

asyncFunc().then((x) => console.log(x));
// 123
```

## Rejecting a \[\[id:14e0ce4b-b4b1-46fe-946a-c519550682ac]\[promise]]

```js
async function asyncFunc() {
  throw new Error("Problem!");
}

asyncFunc().catch((err) => console.log(err));
// Error: Problem!
```
