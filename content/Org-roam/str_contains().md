# str\_contains()

## Description

str\_contains()[^rfc] tells us if string contains other string.

## Syntax

```php
if (str_contains('Lululu I've got some apples, 'apples')) { /* … */ }
```

## Footnotes

[^rfc]: https://wiki.php.net/rfc/str_contains
